> 이 글은 새 글 작성 방법을 설명하는 예시입니다.

## 새 파일 만들기

`_posts/` 폴더에 `2026-11-10-my-first-post.md`처럼 영문 이름으로 파일을 만듭니다. 파일 이름이 글 주소가 됩니다.

파일 맨 위에 아래 정보를 넣습니다.

```yaml
---
title: 오늘 배운 것
date: 2026-11-10
tags: [개발, 기록]
description: 글을 한두 문장으로 소개합니다.
---
```

## 본문 작성하기

`## 제목`으로 소제목을 만들고, 문단 사이에는 빈 줄을 넣습니다. **중요한 문장**은 별표 두 개로 감쌀 수 있습니다.

코드는 백틱 세 개로 감싸고 언어 이름을 적습니다. 링크는 `[표시할 이름](주소)` 형태로 작성합니다.

이미지는 `assets/`에 넣고 `![이미지 설명](/assets/img/파일이름.png)`으로 표시할 수 있습니다. 파일 이름에는 영문 소문자와 하이픈을 사용하면 편합니다.

## 공개하기

GitHub Pages 초기 설정을 마친 뒤 저장소에 변경 내용을 저장하면 자동으로 사이트를 다시 만듭니다. 글 목록과 태그, RSS도 함께 업데이트됩니다.

자세한 초기 설정은 프로젝트의 `README.md`에서 확인할 수 있습니다.
