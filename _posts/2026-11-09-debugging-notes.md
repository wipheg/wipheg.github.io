## 먼저 재현하기

문제가 발생한 입력과 실행 순서를 적습니다. 같은 조건에서 문제가 반복되는지 확인하면, 수정 후에도 같은 방법으로 결과를 비교할 수 있습니다.

## 한 번에 하나씩 확인하기

여러 곳을 동시에 바꾸면 무엇이 원인이었는지 알기 어렵습니다. 의심되는 지점을 하나 고르고, 예상한 값과 실제 값을 비교해 봅니다.

```javascript
function total(items) {
  if (!Array.isArray(items)) {
    throw new TypeError('items는 배열이어야 합니다.');
  }
  return items.reduce((sum, item) => sum + item.price, 0);
}
```
